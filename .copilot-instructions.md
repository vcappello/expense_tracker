# Copilot instructions for Expense Tracker AI

## Obiettivo
Costruire una webapp per monitorare le spese personali con un'interfaccia semplice, leggibile e funzionale per un utente non tecnico.

## Stack
- React + TypeScript + Vite
- Styling con CSS semplice e componenti modulati
- Nessuna dipendenza esterna non necessaria

## Convenzioni
- Il file spec.md contiene le specifiche di progetto e deve essere aggiornato con ogni nuova feature.
- Il file plan.md deve contenere le attività da fare divise in step, mantenendo una struttura chiara e leggibile. Quando uno step avanza deve essere marcato come completato ma non deve essere cancellato. Nel plan.md vanno indicati sia lo sviluppo di nuove feature che la correzione di bug.
- Mantieni l'interfaccia pulita, accessibile e responsiva.
- Priorità a codice chiaro e tipizzato.
- Usa nomi di variabili e componenti in inglese quando possibile, ma mantieni etichette UI in italiano per l'esperienza finale.
- Quando aggiungi nuove funzionalità, preferisci componenti semplici e una struttura a file piccoli.
- Documenta le modifiche rilevanti nel README.

## Criteri di qualità
- Nessun codice non usato o duplicato.
- Verifica il build prima di concludere feature importanti.
- Mantieni la logica di business leggibile e separata dalla UI.
- Preferisci soluzioni pronte all'uso senza overhead inutile.
