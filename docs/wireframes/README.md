# Wireframes / Schizzi UI

Cartella per i wireframe del redesign dell'interfaccia (sezione "User Interface (UI redesign)" di `spec.md`).

## Convenzioni
- Formato: **PNG** o **JPG**
- Un file per schermata, nome auto-esplicativo (es. `main-view.png`, `analytics.png`)
- In `spec.md`, per ogni schermata, indicare il riferimento al wireframe corrispondente
- Allegare le immagini anche nella chat di sviluppo per riferimento durante la codifica
- In alternativa ai disegni, si possono usare brevi note testuali + diagrammi Mermaid in `spec.md`
